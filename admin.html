📌 कैसे Publish करें?

1. Shayari यहाँ तैयार करें।
2. "Copy Data" से data copy करें।
3. "Open GitHub Actions" दबाएँ।
4. वहाँ Add Shayari → Run workflow करें।
5. Shayari की details भरकर workflow चलाएँ।
6. हरा ✅ Success आने के बाद website पर Shayari दिखाई देगी।
